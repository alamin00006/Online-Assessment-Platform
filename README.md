🧩 Project Overview

This platform includes two main panels:

Employer Panel
Candidate Panel

Employers can create and manage exams, and candidates can participate in exams with timer-based submission and behavior tracking.

✨ Features
🧑‍💼 Employer Panel
Login system
Dashboard with exam cards
Create Online Test (multi-step form)
Add / Edit / Delete questions
View candidates
👨‍🎓 Candidate Panel
Login system
Exam dashboard
Start exam
Timer-based exam
Manual & auto submit
Behavior tracking:
Tab switch detection
Fullscreen exit detection
